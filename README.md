Especificaciones sobre el sistema:
1. 1. La carpeta Querys_BD contienen scripts para generar la base de datos con todas sus tablas y Procedimientos Almacenados.
2. 2. El sistema fue hecho con Java with Maven ya que así pudimos usar bibliotecas que nos permitían generar PDFs y un componente que nos permitía establecer fechas en los registros
   además de un driver que permita conectar con la base de datos de MySQL. Esto gracias a que en el pom.xml se pueden colocar <dependencies> que nos permiten usarlas.
   3. La contraseña a la BD es MinuevaContra1 y su puerto en localhost ha sido 3306
